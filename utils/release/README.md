# Release files

Files used by the release workflow `.github/workflows/release.yml`:

- `archive-readme.md`: the `README.md` in the release archives (installed by the top-level `CMakeLists.txt`).
- `release-notes.md`: the text of the GitHub release.

Changes here change what users get. See [how to release](../../docs/how-to-release.md) for the whole process.
